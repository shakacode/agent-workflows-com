> Give your agent a task. Get a verified PR and a clear explanation.

V2 is a pilot for ordinary changes in a trusted repository. One agent owns the
task, uses your repository's existing setup and checks, and brings you a reviewable
result. Codex is the reference host; complete Claude Code and Cursor workflows
remain unverified.

## Start here

1. Follow the [isolated Codex installation and startup guide](/docs/v2/getting-started/).
   It covers prerequisites, a trusted source checkout, and a dedicated pilot
   directory. Start Codex from the separate working directory described there.
2. Give the agent a task description, issue, or PR link and any limits that matter.
   It finds the target checkout from context or asks for its path if needed.
3. Choose **Ask** or **Auto** for this task. If you have already given merge
   instructions, the agent uses them; otherwise it asks early.

After following that installation guide, an ordinary task can start with:

```text
Use ~/agent-tools/agent-workflows-v2-pilot/skills/work-pr-v2/SKILL.md as the trusted workflow.
Fix the settings page so saving an unchanged form preserves the existing values.
Bring the verified PR back for my merge decision.
```

The explicit trusted path is currently required. Installing the pilot does not
make `$work-pr-v2` available automatically. Your repository's `AGENTS.md` and
existing validation commands still apply.

## From task to PR

**Task → implement and clarify → verify → explain → Ask or Auto.**

Questions can happen throughout the work. The agent resolves routine, reversible
choices itself. When a missing requirement, product tradeoff, or wider scope
affects the result, it explains the consequence and recommends a next step before
continuing dependent work. It can continue independent work while waiting;
silence is not approval.

You receive concise progress updates and a PR walkthrough explaining what changed,
why, important code choices, verification, and relevant risks. Supporting evidence
belongs in expandable PR details. See
[working with your agent](/docs/v2/working-with-your-agent/)
for examples of questions, writing preferences, and blockers.

## Ask or Auto

- **Ask:** the agent prepares and explains the finished PR, then requests one
  concrete merge decision. It refreshes the checks before merging the authorized
  revision.
- **Auto:** with your authority for this task, the agent merges an eligible
  ordinary change after the required checks and approvals pass. The walkthrough
  is still required; reading it is not an extra approval step.
- **PR only:** when you ask for a review or a published PR as the deliverable,
  the agent stops there.

Neither choice bypasses failed checks, missing authority, or required approvals.
A changed commit needs fresh verification. Unsupported repository protections
or merge queues produce an explained blocker; the pilot does not schedule a
background retry. Deployment and other consequential actions need their own
authority.

## Evidence you can inspect

For behavior changes, use a meaningful failing check before implementation and
rerun it after the fix. For visible changes, inspect desktop and mobile
screenshots. A short video is useful when interaction or timing matters.
Evidence should identify what was actually tested and any limitations.
See the canonical [tests and visual evidence guide](/docs/v2/verification/).

Available model, reasoning-effort, and native token totals should accompany every
task. Missing data is **UNKNOWN**, not zero. Automatic collection is still being
built; do not assume complete usage attribution or reporting parity across hosts.
Keep prompts, raw sessions, private identifiers, and secrets out of public evidence.

## Keep using it

The [installation guide](/docs/v2/getting-started/#upgrade-or-remove)
also covers source upgrades, rollback, and removing the pilot link. The maintained
guides live in the [V2 source repository](https://github.com/shakacode/agent-workflows-v2).
Use its documented source installation today. RubyGem distribution and complete
clean-host adoption remain pilot work.
